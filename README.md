# Технологии индустриального программирования

Практические работы 1–4 по JavaScript. Каждая работа находится в отдельной папке и запускается независимо, без установки сторонних пакетов.

## Автор

ФИО, группа и номер в журнале ожидают уточнения. До этого в программах используются явно обозначенные демонстрационные данные из методички.

## Работы

1. [Окружение, типы, условия, циклы и отладка](practice-01/README.md).
2. [Функции, объекты, массивы и ES-модули](practice-02/README.md).
3. [DOM, события и фильтры задач](practice-03/README.md).
